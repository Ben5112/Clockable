# Clockable
Clockable - A intuitive Minimalist clock app, with an unlimited customized experience. Made by Claude Sonnet 5.5, Idea from @Ben5112

How to Install: 

For Windows 95 or newer (Not Tested):
Download the Clockable Legacy Edition.exe in the releases page.

For Windows 7 or Newer (Not Tested):
Download the Clockable - Windows 7 Experience.exe in the releases page

For Windows 10 or newer (Constantly Tested):
Download either the Clockable Standard Edition - Portable.exe or the Clockable Standard Edition - Installer.exe in the releases page
